# 项目记忆（.project.md）

> 本文件是项目的唯一事实来源。改代码前先读这里，改完同步更新。

## 1. 项目概述

- **用途**：面向博士生的科研全流程智能体工作台（创新点 → 文献 → 实验 → 论文 → 复盘 → 激励 + 科研画布编排）。参赛作品：2026 年四川省大学生"智能体+"大赛。
- **技术栈**：React 18 + Vite 5 + TypeScript + Tailwind CSS + React Flow(@xyflow/react) + Recharts + react-markdown + pdfjs-dist
- **模版类型**：`react-vite`（平台预设，不可更改）
- **路由模式**：`HashRouter`（平台要求，`/#/…`）
- **代码来源**：`https://github.com/GW19ddd/ResearchPlatform` 的 `growth-workbench/web`（原为 React + FastAPI 全栈应用，本次移植为纯前端）

## 2. 架构决策：为什么没有用平台数据表

原应用是 **FastAPI + SQLite** 全栈程序（146 接口 / 26 表），后端承担 LLM 调用、画布拓扑执行、Zotero 同步、PDF 解析、SQLite 备份。

本平台只托管前端静态资源（无 Python 运行时），因此做了如下替换：

| 原能力 | 新实现 | 位置 |
|---|---|---|
| SQLite 26 张表 | **localStorage 键值存储**（自增 id / DEFAULT / 级联删除语义保持一致） | `src/lib/db.ts` |
| FastAPI 146 接口 | **前端路由表**，124 个前端实际调用的接口全部实现 | `src/lib/api.ts` + `src/lib/api/*.ts` |
| 服务端 llm.py 调模型 | **浏览器直连 provider**（已实测 DeepSeek 返回 CORS 头，允许跨域） | `src/lib/llm.ts` |
| 服务端画布执行引擎 | **前端拓扑执行引擎**（异步后台 + 页面轮询） | `src/lib/api/canvas.ts` |
| Zotero / Gloss / 备份 / SQLite 导出 | **优雅降级**（返回正确结构 + 明确提示，不抛错） | `src/lib/api/misc.ts` |

**为什么选 localStorage 而非平台数据表**：比赛截止仅剩约 28 小时，localStorage 零外部依赖、零失败风险，且每位评委拿到的是隔离且预置好的干净数据（多人共用一张表反而会互相污染）。原产品"数据主权、本地单文件"的设计哲学也与此一致。

> 平台数据表技能（`datatable-for-page-api`）本次**未使用**。若后续要改回平台存储，替换 `src/lib/db.ts` 的实现即可，上层 API 与页面无需改动。

## 3. 运行时配置（关键）

### LLM API Key —— 上线前必须配置

平台 token 额度不足以支撑演示，AI 能力走**使用自带 Key**。默认 provider 为 DeepSeek，`api_key` 初始为空。

- 配置入口：应用内「设置」页 → LLM provider → 填 API Key → 点「测试连接」
- 存储位置：localStorage 的 `wb-db:data` 中 `settings.llm_config`
- **未配置时的表现**：AI 功能返回明确提示「未配置 API Key」并给出操作指引，不会崩溃

⚠️ **评委点开链接时不会自己去填 Key**。正式提交前必须预置一个可用 Key，否则 AI 功能对评委不可见。

### 预置 Key 的两种方式

1. **改默认值**：修改 `src/lib/llm.ts` 的 `defaultConfig()`，把 `providers[0].api_key` 填成真实 Key（注意：打包后的 JS 能被扒出，请用限额 Key 并在赛后作废）
2. **走设置页**：在浏览器里配置好后导出 localStorage 的 `wb-db:data`，作为初始数据写入

## 5. 关键约定

- **接口路径**：领域模块里注册的 pattern **不带 `/api` 前缀**，页面调用时带（`api.ts` 会剥掉）。
- **DEL 与 DELETE**：前端 `del()` 对应 `route('DELETE', …)`。
- **写后刷新**：写操作不回填 id，调用方应重新拉取列表刷新。
- **积分保护下限**：周净分低于 `weekly_net_floor`（默认 -100）后不再扣，且不写 `points_ledger`。见 `src/lib/api/points.ts` 的 `award()`。
- **画布执行**：`POST /canvas/:id/run` 立即返回 `run_id`，执行在后台进行，页面轮询 `GET /canvas/runs/:id`。单节点重跑（`force=false`）会复用祖先节点的历史成功输出。
- **幂等**：`idem` 选项让同 key 并发请求复用同一 Promise，防双击写两条。
