浮层进出 overlay / dialog / drawer

打开时遮罩淡入、面板浮起 / 抽屉滑入；关闭时先播退出动画再卸载，不再瞬间消失。

减少动态效果

系统开启「减少动态效果」后，所有动画时长压到 0.001ms、浮层立刻卸载；点击反馈保留为即时亮度变化，不再有缩放与位移。
